# UMKM — Access Rules

## User Role

Role yang melekat langsung pada `User`:

- `SUPER_ADMIN`
- `ADMIN`
- `USER`

Role ini berlaku secara global pada sistem.

## Permissions

| Action      | SUPER_ADMIN | ADMIN | USER |
| ----------- | :---------: | :---: | :--: |
| View UMKM   |     ✅      |  ✅   |  ❌  |
| Create UMKM |     ✅      |  ✅   |  ❌  |
| Edit UMKM   |     ✅      |  ✅   |  ❌  |
| Delete UMKM |     ✅      |  ❌   |  ❌  |
